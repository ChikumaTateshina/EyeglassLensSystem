WHAT IT DOES

YOUR FIRST LENS

3つの度数から、
レンズをつくる。

01

元になる面を用意。

レンズ前面だけの開いたMeshを指定します。三角形に分割された面でもOK。フレーム・裏面・側面は含めません。

FBX本体を選択 → Model → Read/Write Enabled をON → Apply。

02

Settingsを作り、度数を入力。

Projectの右クリック → Create → Prescription Lens → Settings。元Meshを指定し、球面度数・円柱度数・軸度を入力します。CYLが0なら軸度は不要です。

屈折率や厚みは表示用の既定値で処理されます。必要なときだけ「詳細設定」を開いて調整できます。

03

プレビューして、保存。

プレビューで形状を確認し、レンズを生成・保存。Settingsの隣の Generated にMesh・Material・Metadataが保存されます。元Meshは変更しません。

04

アバターのレンズへ割り当て。

生成MeshをMeshFilter、生成MaterialをMeshRendererに設定します。アバター上に専用スクリプトは不要です。

左右で度数が異なる場合は、片眼ごとに別のSettingsから生成します。左右同じ度数なら、分離した2枚を1つのMeshとして指定できます。

A CLEAR FRAME

フレームの二重映りを防ぐ。

フレームが屈折用背景に入らないよう、レンズ描画の後にフレームを描きます。フレームが複数Materialを使う場合はすべて設定してください。

BEFORE YOU GO

困ったときに。

「Enable Read/Write on the source mesh importer」と表示されます。

ProjectでFBX内のMeshではなくFBX本体を選択します。InspectorのModelタブでRead/Write EnabledをONにし、Applyを押して再生成してください。

三角形が横向き、または面積がゼロというエラーが出ます。

詳細設定のAuto Orient Sourceを有効にしてください。Scene上とMesh内部の軸が異なるFBXも自動判定します。それでも失敗する場合は、フレームや側面が混ざっていないか、重複頂点・面積ゼロの三角形がないか確認します。

Materialの度数を変えたら、Meshの厚みも変わりますか？

Materialで変わるのは像の変形です。度数と形状を揃えて変更する場合は、SettingsからMeshとMaterialを再生成してください。

屈折率やレンズの厚みがわかりません。

度数3項目のみで使えます。屈折率1.60、Base Curve 4D、中心厚1.5mm、最小厚1mmなどの表示用既定値を使います。実際の製品仕様を処方値から推測するものではありません。

SkinnedMeshRendererでも使えますか？

生成Meshにはボーンとウェイトを含みません。SkinnedMeshRendererで使用する場合は別途設定が必要です。通常はMeshFilterとMeshRendererで使用します。

VRChatのVRモードで検証済みですか？

Stereo用マクロを実装し、D3D11で通常描画・Instancing・StereoのShaderバリアントをコンパイル検証しています。VRChat実機・HMD・ミラー描画は未検証です。使用環境で確認してください。

このシステムの光学表現について

画面空間屈折による視覚近似です。実際の視覚を再現するものではなく、眼鏡製造・診断・視力評価には使いません。透明物の描画順や、最初のGrabPassより後に描画される背景には制約があります。
